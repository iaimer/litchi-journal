### 自适应前景缩放边缘缺少安全余量

原前景宽 57dp。原测试仅覆盖 xxxhdpi 并忽略 alpha≤10 的像素，mdpi 的可见边缘最大半径达 33.444dp；检查所有 alpha>0 像素时，五种密度均超出 33dp 安全半径（最大 34.533dp）。与计划中「确保安全区」和文档中「全部图形落在中心安全圆」不一致。

先将回归扩展到五种密度、所有非透明像素，得到 5 项失败；再将派生前景宽改为 54dp。修复后独立像素遍历的最大半径分别为 32.319、32.087、31.688、31.500、31.522dp，全部小于 33dp。浅白背景及系统裁切方式不变。

### 书本外仍有低透明阴影残留

母版下沿外 `(129,330)`、`(205,350)` 的 alpha 均为 14，与计划「去除阴影」不符。先加入透明像素断言复现失败；随后派生脚本清除距 alpha≥128 实体轮廓超过 2px 的低透明像素，保留实体及邻近抗锯齿。

与上一轮 APK 内原始母版逐像素对比，清理 5195 个低透明像素，实体像素变化为 0；构图、荔枝、翻页与爱心不变。母版及各平台资源重新同源派生，重复执行结果一致。
