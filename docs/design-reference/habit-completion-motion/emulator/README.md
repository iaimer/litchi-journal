# 习惯完成反馈模拟器验收（历史媒体）

2026-10-17，在 Android 16 / API 36 的 `test_36` 模拟器验收。使用临时 Debug 入口，复用真实 `HomeScreen`、`HabitCard`、饮水/步数/时长面板及保存回调；API 响应与习惯设置使用内存测试数据，不连接真实服务器，不写 Vault。本目录不包含发布 APK。

本页说明保留媒体的采集条件，不能作为当前1.10.0整体验收；当前状态见 [HANDOFF.md](../../../../HANDOFF.md)。

## 结果

- 阅读和学语言已有勾选及 5 分钟记录，当前目标为 10 分钟；长按设为 10 分钟后正常画勾并保存。阅读录屏逐帧确认短笔、长笔和局部庆祝，自定义时长设为 10 分钟也保存成功。
- 饮水从 1250 增至 1500 mL、运动从 5999 改为 6000 步，原有面板入口可用；内置和自定义 checkbox 保存后正常显示完成。
- 延迟保存失败后恢复未完成，显示“更新失败”；请求未结束时再次点击只提交一次。
- 减少动态效果、Ticker 停用、路由遮挡及返回前台后，保存结果正确，恢复后状态圈无补播。像素检查结果见 `interruption-results.json`。前台恢复首次截图受 Android 整窗淡入和位移影响；临时关闭系统窗口/过渡动画后复核通过，应用动画缩放始终为 1，系统设置随后恢复为 1。
- 常规宽度浅深色，以及 320dp / 1.3 倍字体浅深色无溢出，模拟器 `flutter:E` 日志无异常。显示密度已从测试用 540dpi 恢复原始 420dpi。
